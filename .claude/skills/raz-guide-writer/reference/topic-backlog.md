This list exists specifically to close the content gaps found when auditing madebyraz.co.il's 28 guides against Red Ghost (red-ghost.co.il), a direct competitor: they lean heavily on (1) industry/vertical-specific guides, (2) comparison/decision-format content, (3) year-tagged freshness on time-sensitive topics, (4) automation/CRM/WhatsApp-bot angles tied directly to services sold. Raz's original 28 guides were almost entirely generic/topical with none of the above except a couple of comparisons — this backlog corrects that skew going forward.

## How to add more (when the list above is empty)

Follow the same four buckets: a new professional vertical not yet covered, a new comparison/decision topic relevant to Raz's actual services (web design, WordPress, AI video/visual content, site upgrades), a time-sensitive topic worth year-tagging, or a concrete automation/integration angle. Check the `guides` table first so you don't duplicate an existing slug or topic. Keep titles in the exact register described in `voice-and-structure.md`.
