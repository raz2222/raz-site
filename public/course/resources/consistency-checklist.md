# צ'קליסט — עקביות דמות ולוקיישן

*משאב מקורי של הקורס.*

---

## למה זה נכשל

למודלים אין זיכרון של דמות. כל פריים/ריצה = פרשנות חדשה. "אישה עם שיער חום" =
מאות פנים תקפות. הנדידה מצטברת לאורך שוטים.

---

## לפני שמתחילים סדרת שוטים — עבור על הכל

### דמויות

- [ ] כל **פנים חוזרות** = Soul ID מאומן (אדם אמיתי: 20+ תמונות מגוונות, עד 80;
      מומצא: AI Influencer / Soul Cast → אצווה של פורטרטים → Soul ID).
- [ ] Soul ID מודל-ספציפי — אומן ל-Soul 2.0? לא זמין ב-Soul Cinema. לאמן בנפרד.
- [ ] הדמות שמורה כ-**Element** (דמויות Soul מופיעות אוטומטית).
- [ ] 2+ דמויות בסצנה = כמה Elements בפרומפט אחד.
- [ ] אדם אמיתי — אימנת Soul ID **לפני** יצירת Element מהפורטרטים?

**תמונות Soul ID — עוזר / מזיק:**
זוויות והבעות מגוונות / אותה תנוחה · אור ברור / צללים קשים · עדכני / מיושן ·
לפחות תמונה בגובה מלא / רק ראש · בלי משקפי שמש-כובעים / איתם · סובייקט יחיד / קבוצה.
מצפים ל"בבירור אותו אדם", לא פיקסל-מדויק.

### לוקיישנים (החצי הקשה)

- [ ] כל **מקום חוזר** = תמונת רפרנס אחת → Create Element (ב-Cinema Studio: טיפוס
      Locations).
- [ ] הלוקיישן מוזן **באותה ג'נרציה** עם זהות הדמות — לא בנפרד.
- [ ] נעלת ב-POSITIVE LOCKS: מיקום רהיטים, כיוון אור, צבע קיר, מה בחלון, שעה,
      טקסטורות, פרופס על מדף.

### פרופס / מוצר / מראה / קול

- [ ] פרופ/מוצר חוזר = Element (עם טקסט-לוגו מדויק בפרומפט).
- [ ] מראה/grade = `@style` רפרנס או grade קבוע.
- [ ] קול = preset משובט + אותו כיוון משחק בין קליפים.

### בין שוטים

- [ ] משנים **משתנה אחד** באיטרציה — פרומפט *או* רפרנס.
- [ ] משרשרים את **הפריים האחרון של שוט A → הפריים הראשון של שוט B**.
- [ ] מפנים דרך Element — לא מעלים מחדש בכל קליפ.

### קוואירק Kling

תמונה מחוברת ישירות = פריים פתיחה, לא רפרנס דמות. ליצור Element קודם, אז
`@element-name` בפרומפט.
